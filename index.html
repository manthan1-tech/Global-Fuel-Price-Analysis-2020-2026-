About the project

Understanding fuel-price trends

This project presents an interactive view of global fuel prices and taxation trends from 2020 to 2026. The visualizations are hosted on Tableau Public and embedded below.

Project objective

Make it easier to explore fuel-price patterns over time and compare differences between countries using interactive visualizations.

How to explore

  • Start with the dashboard for the overall analysis.
  • Use available Tableau controls and filters to explore the views.
  • Continue to the story for the top-three-country comparison.
